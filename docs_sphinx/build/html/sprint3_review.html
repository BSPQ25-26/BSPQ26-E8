Sprint 3 Review Guide¶

This section summarizes what should be shown during the Sprint 3 review.

Mandatory Review Points¶

  • Sprint goal and backlog board

  • Task distribution and traceability (issues, commits, comments)

  • Jenkins build and test execution

  • Documentation hosted in GitHub Pages

  • Demo of the third release

  • Sprint conclusions: events, difficulties, lessons learned

Submission-Oriented Checklist¶

  • Functionality complete

  • Tests updated for new functionality

  • CI passing

  • Documentation complete

  • Logging in tests uses SLF4J or Log4J (no System.out.println)

Documentation Deliverables¶

The Sphinx documentation in this repository includes:

  • Project overview

  • Architecture description

  • Local setup and execution instructions

  • High-level API reference

  • Testing and CI summary
